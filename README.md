## About the Project

This portfolio showcases my software engineering projects, technical skills, academic background, and professional experience.

I'm a Computer Science senior at California State University, Los Angeles, interested in software engineering, full-stack development, artificial intelligence, and machine learning.

Rather than using a traditional portfolio landing page, I designed an **Interactive Blueprint Workstation**, featuring an isometric developer workspace where visitors can explore different sections by interacting with objects on the desk.

The interface combines a dark navy color scheme, cyan accents, responsive layouts, and interactive navigation.

## Features

### Interactive Blueprint Workstation

The homepage features four interactive hotspots:

| Workstation Object | Destination |
|---|---|
| Main Monitor | Featured Projects |
| Notebook / Planner | Education, Coursework & Resume |
| Circuit Board | Technical Skills & Tech Stack |
| Coffee Cup | Contact & Socials |

Each desktop hotspot includes glowing cyan hover effects, animated indicators, tooltips, and click-to-scroll navigation.

### Responsive Design

- Responsive layouts for desktop, tablet, and mobile devices

- Touch-friendly buttons and navigation

### Additional Features

- Technical blueprint-inspired project cards

## Getting Started

### Prerequisites

- Node.js (a version compatible with the project's Vite dependencies)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/FLung13/portfolio.git
```

**2. Navigate into the project**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed by Vite, typically `http://localhost:5173/`.

### Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The website is deployed using **Vercel** with GitHub integration.

Updates merged into the configured production branch trigger new deployments. Feature branches can be tested using Vercel preview deployments before publication.

**Production URL:** [https://fredylung.dev/](https://fredylung.dev/)
